# Security

This portfolio is a public website. Do not commit or upload:
- passwords
- API keys
- private financial data
- non-public employer/client data
- personally sensitive documents that are not intended for public viewing

Public portfolio assets belong under `public/`.

Production deployment should use HTTPS. Vercel provides HTTPS automatically for Vercel and connected custom domains.

The project sets conservative security headers in `next.config.ts`.
